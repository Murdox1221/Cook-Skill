# Example rotation (style reference)

Five example weeks that show how this household eats — the cadence, the side
dishes, how often a Mexican night / pasta night / breakfast-for-dinner / FFY
night comes up. **This is a baseline for suggestions, not a fixed schedule.** The
planner draws on it and extends it with similar new ideas; edit it when the
household's habits shift.

"FFY" = fend for yourself: no dinner cooked, nothing to buy for it.
